## Inventory Mangement Project
This is a Python-based program that helps the inventory management system work accurately and more reliably. It makes sure to manage different products in an organized form and allows users to understand it easily.

## Main Features

 Add Products:Allows users to add different products to the inventory.
 View Products: Displays the available products with their names, prices, and quantities.
 Manage Stock:Updates product quantities when new stock is received.
 Record Sales: Allows users to sell products and reduces the available stock.
 Stock Availability: Checks whether enough stock is available before selling products.
